# runpod/orchestrator/requirements.txt

# Free, open-source Telugu STT + TTS stack:
#  - STT: faster-whisper, running a Telugu-finetuned Whisper checkpoint
#         (vasista22/whisper-telugu-medium), converted to CTranslate2 format
#         at Docker build time (see Dockerfile).
#  - TTS: ai4bharat/indic-parler-tts (via the `parler-tts` package), free
#         open weights built for Indian languages including Telugu.
#  - LLM: GPT-4.1-mini via the official `openai` SDK (gpt_client.py) — the
#         only paid-per-call piece in this stack.
#
# Targets the Linux GPU container described in the Dockerfile. Don't
# `pip install -r requirements.txt` directly on Windows/Mac — use
# requirements-dev.txt + LOCAL_DEV=1 for local testing instead (see README).
